# Navodila za poganjanje

Aplikacija je dostopna na url: https://rozinatimotej.github.io/ToneBird

Za igro je potreben mikrofon.

### V primeru lastnega poganjanja
- Kloniranje git repozitorija (git clone)

- IDE ki podpira "Live server" (WebStorm ali Visualstudio) namestitev razširitve (VScode: https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer)

- Zagon "Live server" (desno spodaj v orodni vrstici) odpiranje index.html (privzeto: http://127.0.0.1:5500/)

- Uživajte v igranju!
